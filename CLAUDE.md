# Round 2 — Reverse Engineering Roulette

## Project Requirements

- This is a frontend-only project.
- Do not add a backend.
- Do not add a database.
- Do not add API routes.
- Do not add authentication.
- Do not add payment functionality.
- Use client-side state and local data.
- Do not modify or push to main/submain.
- Work on the current feature branch.
- The website is the Round 2 reference website for Reverse Engineering Roulette.
- The target difficulty is medium.
- The theme is SDG 12 — Responsible Consumption and Production.
- The website should be an interactive sustainable marketplace called EcoMart.

## Development Rules

- Inspect the existing project before modifying it.
- Preserve the existing Next.js architecture.
- Use reusable components.
- Avoid unnecessary dependencies.
- All interactions must actually work.
- Test the application before considering the task complete.
- Ensure the production build succeeds.
